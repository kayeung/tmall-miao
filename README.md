## 直接下载（推荐，Windows x64）

到 [Releases](https://github.com/kayeung/tmall-miao/releases/latest) 下载
`tmall-assistant-v20261111-L-win64.exe`，**双击即可运行**（内置 adb + OCR，无需安装 Python）。

手机先开启 USB 调试并连接电脑，然后按提示选择：
设备类型 `2`（安卓）→ 连接方式 `1`（USB）→ 任务 `0/1/2` → 启动模式 `1`（自动搜索进入）。

> exe 由 PyInstaller 打包，单文件约 75 MB，首次启动会解压到临时目录，稍慢属正常。
> 若被杀毒软件拦截，请添加信任（PyInstaller 单文件程序的常见误报）。

## 从源码运行



1. 安装 Python 3.8+（推荐 3.10）
2. 安装依赖：

```bash
pip install -r requirements.txt
```

3. 手机开启「开发者选项 → USB 调试」，数据线连电脑，确认能看到设备：

```bash
adb devices
```

4. 运行：

```bash
python main.py
```

依次选择：设备类型 `2`（安卓）→ 连接方式 → **要操作的淘宝（主应用 / 应用分身）** → 任务脚本 → 启动模式（自动搜索进入 / 手动进入）。

> 用 vivo/OPPO 的「应用分身」登录淘宝时，第 3 步要选 `2. 应用分身`，
> 这样启动和分身选择弹窗都会自动选带 `Ⅱ` 标识的那个实例。

## 任务脚本选择

```
0. 金币+能量 一键完成
1. 金币任务（去赚金币）
2. 能量任务（去赚能量）
3. 芭芭农场（领肥料/集肥料）
5. 退出程序
```

活动入口：淘宝首页搜索栏搜索「淘金币双11狂享20亿」，脚本会自动完成这一步。
活动页底部有两个按钮，分别对应两套任务面板：

| 面板 | 累计奖励 | 说明 |
|---|---|---|
| 赚金币抵钱 | 3 / 10 / 20 次 | 金币任务，卡片的名称/动作/奖励是三个独立节点 |
| 做任务赚能量 | 5 / 20 / 50 次 | 能量任务，卡片把「名称(x/n)+动作+奖励」合并成一行 |

两套流程的规则一致：

- 自动完成「浏览15秒」「浏览5秒」类任务；
- 自动领取已完成的单任务奖励；
- 自动领取累计奖励（达标后金币面板出现「立即领取」，能量面板对应方块变为可领取）；
- 跳过需要跳转支付宝/头条等外部 App 的任务（蚂蚁庄园、蚂蚁森林、支付宝农场、金豆夺宝、头条极速版），以及答题类任务。

## 芭芭农场

菜单选 `3`，脚本会：搜索「芭芭农场」→ 点搜索框下方卡片右上角「进入」→ 关掉推广弹窗/滑块验证 →
点右侧「点击领取」领每日肥料 → 点底栏「集肥料」展开「做任务赚肥料」→ 逐个做浏览类任务。

- 农场页是 canvas 渲染：底栏按钮按比例点并带 5 个偏移位自动校准；
  任务面板滚动后无障碍树不会刷新，因此任务行用 OCR 读屏识别（exe 已内置 OCR 模型）；
- 实测会跳转外部 App 的任务（哪怕名字里没有“支付宝”）会被自动拉黑，不会重复触发；
- 跳转支付宝的任务（逛逛支付宝芭芭农场、支付宝蚂蚁森林、前往支付宝横幅）一律跳过；
- 运行前同样会静音。

## 对手机系统设置的影响

脚本运行期间会临时改两项设置，**程序退出时会自动还原**：

| 设置 | 用途 | 还原方式 |
|---|---|---|
| `global stay_on_while_plugged_in` | 充电/插 USB 时不熄屏，避免跑到一半黑屏 | 退出时写回运行前的原值 |
| 媒体音量 | 静音 | 退出时写回运行前的音量 |

> **v20261111-I 及更早版本只设置、不还原**，会让手机出现「充电时屏幕只变暗、永远不熄屏」。
> 如果已经被影响，手动执行一次即可恢复：
>
> ```bash
> adb shell settings put global stay_on_while_plugged_in 0
> # 或者
> adb shell svc power stayon false
> ```

## 实现要点

- **任务识别**：不写死 XPath。先把 UI 层级拍平成节点，再按「按钮文案 + 几何位置」把每行卡片拼出来；
  金币/能量两种卡片格式各有一个解析器，动作类型（浏览 / 跳转 / 答题）从文案判断。
- **浏览计时**：H5 任务页每 1.2 秒做一次拟人滑动（波形轨迹 + 随机抖动），因为部分任务的倒计时
  只有滚动才推进；商品详情页不滑动（视频自动播放），避免误触跳转。
  停留时长按卡片写的 15 秒 / 5 秒自动取，实际给 20 / 10 秒余量。
- **搜索类任务**：进入「搜索有福利」页面时，自动点「搜索发现」的第一个推荐词再开始浏览。
- **面板扫描**：面板可以上下滚动，脚本先扫当前屏，没任务就滚动，滚到底再回顶部扫一遍；
  仍没有就关闭面板重新打开（任务表每次打开可能多出新任务）。
- **入口定位**：活动页是 canvas 渲染，无障碍树里没有入口按钮文案，所以从截图里找
  「升级赛车拿钱」黄色横幅的真实位置再点，避免页面轻微改版后点空。
- **搜索类任务**：进入搜索页后先点「搜索发现」里的第一张卡片，再滑到商品页浏览够时长，
  最后按层数返回（H5 搜索页是浮层返回一次，原生 SearchActivity 需要再返回一次）。
- **启动方式**：安卓侧优先用 `am start -n <包名>/<启动Activity>` 显式启动。
  vivo/OPPO 会拦截 monkey 和隐式 LAUNCHER intent，只发隐式意图是拉不起 App 的。
- **应用分身**：分身跑在独立用户空间（vivo 是 user 999），所以启动/停止都带 `--user`，
  分身选择弹窗按启动时选的实例自动点（主应用 / `Ⅱ·淘宝`）。
- **尽量不重启 App**：任务结束后如果没回到活动页，先在 App 内连续返回首页再重新搜索；
  只有彻底回不去才重启。避免杀进程回桌面、再次触发分身选择框。
- **新版金币面板**：面板改成「今日速赚淘金币」后，顶部是「额外得金币」任务行（点标题进入），
  下方「更多金币等你赚」需要点「展开」再往下滑才会露出完整任务清单。脚本会先询问是否执行顶部任务。
- **vivo 应用分身弹窗**：若弹出「选择要使用的应用 / Ⅱ·淘宝」，脚本会自动点主应用。
  也可以在 `设置 → 应用 → 应用分身` 里把默认打开方式设为原始应用，彻底免掉这个弹窗。
- **锁屏**：运行前会点亮屏幕并尝试解锁（无密码可自动上滑解锁），有密码时会明确报错提示。
- **外部 App 干扰**：任务跳到支付宝时只把淘宝切回前台，不点任何授权弹窗；
  若支付宝首启隐私弹窗反复抢焦点，会强制停止该 App。

## 常见问题

**任务面板打不开？**
脚本会先退回活动页重试，失败则重启淘宝重新搜索进入。仍不行请在启动时选「2. 手动进入活动页」，
自己进到活动页后再回车。

**跑一半跳到支付宝/商品详情？**
浏览过程中若被带到外部 App，脚本会切回淘宝；商品详情页会自动播放计时，不会被强行返回。

**vivo/OPPO 上脚本打不开淘宝？**
系统会拦 monkey 和隐式启动，脚本已改用显式组件启动；如果手机上开了「应用分身」，
启动时会出现「选择要使用的应用」，脚本会自动点主应用。若经常弹，建议在
`设置 → 应用 → 应用分身` 里设置默认使用原始应用。

**「搜一搜」类任务不动？**
这类任务会先打开搜索页，需要点「搜索发现」里的卡片进商品页再浏览。脚本会自动点第一张卡片；
如果搜索页加载特别慢，会等最多 8 秒再点。

**日志在哪？**
默认输出到终端，`python main.py --log INFO` 可调日志级别；DEBUG 会打印每一轮面板的全部任务。
